# Han Xi UX Portfolio

An English-language portfolio featuring product design, UX research, data analysis, prototyping, and visual communication work by Han Xi.

## Portfolio

- GitHub Pages: https://hanxi0130-netizen.github.io/hanxi-ux-portfolio/
- Vercel mirror: https://hanxi-ux.vercel.app

## Structure

- `dist/index.html` — portfolio homepage
- `dist/scale.html` — SCALE self-care UX research case study
- `dist/tetris.html` — TETRIS product and interface case study
- `dist/selected-work.html` — selected product, space, and identity work
- `dist/assets` and `dist/media` — project images

The site is static and requires no build step.
